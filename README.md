# WinDirStat en Français pour Windows

**WinDirStat en français pour Windows** est un outil gratuit et open source permettant d’**analyser l’espace disque**, de trouver les fichiers volumineux et de comprendre rapidement ce qui occupe l’espace de stockage de votre ordinateur.

Ce projet vise à faciliter l’utilisation de WinDirStat par les utilisateurs francophones en proposant une version localisée pour Windows tout en conservant les fonctionnalités du projet original.

## Qu’est-ce que WinDirStat ?

WinDirStat est un **analyseur d’espace disque pour Windows** qui permet de visualiser l’utilisation du stockage de votre ordinateur.

L’outil analyse les disques et les dossiers et présente les résultats sous forme de liste et de représentation graphique Treemap.

Cette visualisation permet de trouver rapidement les fichiers et dossiers qui occupent le plus d’espace.

Si votre **disque est plein** et que vous ne savez pas pourquoi, WinDirStat peut vous aider à identifier les fichiers volumineux, les dossiers importants et les données qui utilisent votre espace de stockage.

## Pourquoi utiliser un analyseur de disque ?

Au fil du temps, les téléchargements, vidéos, images, fichiers temporaires, sauvegardes et programmes peuvent occuper une grande quantité d’espace.

Windows fournit certaines informations sur le stockage, mais un analyseur de disque permet d’obtenir une vue beaucoup plus détaillée du contenu d’un disque.

WinDirStat organise les données de manière visuelle afin de vous permettre de comprendre rapidement où l’espace disque est utilisé.

## Quelles sont les principales fonctionnalités ?

* Analyse de l’espace utilisé sur les disques et dossiers
* Visualisation graphique de l’utilisation du stockage
* Treemap pour identifier les fichiers volumineux
* Liste des fichiers et répertoires
* Tri par taille et type de fichier
* Affichage par extension
* Recherche de fichiers
* Filtres pour analyser le contenu
* Identification des fichiers en double
* Informations détaillées sur la taille des fichiers
* Intégration avec l’Explorateur Windows
* Outils de nettoyage
* Prise en charge des volumes NTFS
* Version portable disponible dans certains releases
* Compatibilité avec Windows 10 et Windows 11

## Comment analyser l’espace disque sous Windows ?

1. Téléchargez la dernière version depuis la page [Releases](../../releases).
2. Installez WinDirStat ou utilisez la version portable lorsqu’elle est disponible.
3. Lancez le programme.
4. Sélectionnez le disque ou le dossier que vous souhaitez analyser.
5. Attendez la fin de l’analyse.
6. Utilisez la liste des fichiers et le Treemap pour identifier ce qui occupe le plus d’espace.

Après l’analyse, vous pouvez rapidement identifier les fichiers et dossiers les plus volumineux de votre ordinateur.

## Comment trouver les fichiers volumineux ?

Une fois l’analyse terminée, consultez la taille des fichiers et des répertoires affichés par WinDirStat.

Le Treemap facilite cette recherche : plus un fichier ou un dossier occupe d’espace, plus sa représentation graphique est importante.

Vous pouvez ainsi identifier les vidéos, fichiers d’installation, sauvegardes, téléchargements ou autres données qui occupent beaucoup d’espace.

Avant de supprimer un fichier, vérifiez toujours qu’il n’est pas nécessaire à Windows ou à un autre programme.

## Comment libérer de l’espace disque ?

Commencez par utiliser WinDirStat pour déterminer quels fichiers et dossiers occupent le plus d’espace.

Après avoir identifié les données inutiles, vous pouvez notamment :

* Supprimer les fichiers temporaires
* Nettoyer les anciens téléchargements
* Supprimer les fichiers volumineux dont vous n’avez plus besoin
* Déplacer vos fichiers personnels vers un autre disque
* Archiver des documents et des fichiers multimédias
* Désinstaller les programmes que vous n’utilisez plus

Soyez prudent avec les fichiers système et les fichiers dont vous ne connaissez pas l’utilité.

Oui. WinDirStat peut être utilisé pour analyser les disques et les dossiers sous Windows 10.
